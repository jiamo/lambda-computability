# proofs/statements/

The exact Lean statements of the properties are written over Aristotle's internal formal encoding
of C programs, which cannot be exported (see `../README.md`). The statement of every property of
rounds 1 and 2 is given in precise prose in `../../PROOFS.md`, in terms of the C functions and of
the reference definitions they name (`../../spec/CTSpec.lean` for round 1, the `Start/`
modules named in each entry for round 2).
