# M7-ML-RANDOMNESS-FRAMEWORK

**Status:** DONE_STRONG

Module `Start/MartinLof.lean`, imported by `Start.lean`.  This is the measure-theoretic layer of
algorithmic randomness, on top of `Start/Kraft.lean`, `Start/ChaitinOmega.lean` and
`Start/OmegaIncompressible.lean`.

## Definitions

* `Lambda.cantorMeasure` — the fair-coin (uniform) probability measure on Cantor space
  `ℕ → Bool`, built from Mathlib's infinite product measure `MeasureTheory.Measure.infinitePi`.
* `Lambda.cylinder σ` — the basic clopen set of sequences extending the finite string `σ`, with
  `Lambda.cantorMeasure_cylinder : cantorMeasure (cylinder σ) = 2⁻¹ ^ σ.length`.
* `Lambda.openOf W` — the open set generated by a set of finite strings, with the subadditivity
  bound `Lambda.cantorMeasure_openOf_le`.
* `Lambda.MLTest` — a **Martin-Löf test**: a uniformly `Σ⁰₁` sequence of open subsets of Cantor
  space whose `c`-th member has measure at most `2 ^ (-c)`.  The `Σ⁰₁` data is in the usual
  normal form: a computable matrix `enter c σ j`, "the string `σ` has entered the `c`-th set by
  stage `j`".
* `Lambda.MLRandom X` — `X` escapes some level of every Martin-Löf test.

## Theorems

* `Lambda.kraft_kolmP_ennreal : ∑' s, 2⁻¹ ^ kolmP s ≤ 1` — Kraft's inequality for prefix
  complexity, transported to `ℝ≥0∞`.
* `Lambda.not_mlRandom_of_computable` — **no computable sequence is Martin-Löf random.**  The
  witnessing test `Lambda.prefixTest` enumerates the prefixes of `X` of length at least `c`; its
  `c`-th open set is exactly the cylinder of `X ↾ c`, of measure `2 ^ (-c)`.
* `Lambda.exists_const_le_kolmP_prefix_of_mlRandom` — **the easy half of the Levin–Schnorr
  theorem**: if `X` is Martin-Löf random then `∃ c, ∀ n, n ≤ kolmP ⌜X ↾ n⌝ + c`.  The witnessing
  test `Lambda.compressTest` collects at level `c` the strings compressible by more than `c`
  bits; `Lambda.primrec_compressEnter` makes it `Σ⁰₁` and Kraft's inequality bounds its measure
  by `2 ^ (-c)`.

Gates: `lake build` succeeds; no `sorry`; no linter warnings; `#print axioms` on the two main
theorems reports only `propext, Classical.choice, Quot.sound`.

## Boundary

The **converse** half of Levin–Schnorr — incompressibility implies Martin-Löf randomness — is
not proved, and is not available for this machine.  It rests on the Kraft–Chaitin machine
existence theorem applied to an *additively optimal* prefix machine, and the machine underlying
`Lambda.kolmP` (closed lambda terms under the self-delimiting code `Lambda.bits`, with no input
stream) is not additively optimal: writing `ℓ` arbitrary payload bits into a lambda term costs
strictly more than `ℓ + O(1)` bits.  Consequently Chaitin incompressibility for `Ω`
(`Lambda.exists_const_le_kolmP_omegaPrefix`, `M7-OMEGA-INCOMPRESSIBLE`) does **not** yield
`Lambda.MLRandom` for the bit sequence of `Ω`, and the Martin-Löf randomness of this project's
`Ω` remains open — see `M7-OMEGA-ML-RANDOM`.
