## The question

Rice's theorem (`Start/Scott.lean`, for the lambda calculus) says that no non-trivial extensional
class of programs is decidable.  Rice–Shapiro is the sharper statement about the classes that are
merely *recursively enumerable*: such a class is determined by its finite members.

## Set-up

* `Lambda.Post.acc e s x` — the `e`-th machine accepts `x` within `s` steps, primitive recursive
  (`Lambda.Post.primrec_acc`, from `Nat.Partrec.Code.primrec_evaln`), monotone in the stage
  (`Lambda.Post.acc_mono`), bounded by the stage (`Lambda.Post.acc_bound`, from
  `Nat.Partrec.Code.evaln_bound`), and exhausting the set (`Lambda.Post.Wset_iff_exists_acc`).
* `Lambda.Post.exists_index_of_test` — a uniformly computable family of tests `g n x s` names a
  computable family of r.e. sets: there is a computable `h` with `W (h n) = {x | ∃ s, g n x s}`.
  This is `Lambda.Post.exists_index_fun` (the s-m-n theorem) applied to an unbounded search.
* `Lambda.Post.Extensional A` — the predicate `A` on indices depends only on the set named.
* `Lambda.Post.false_of_compl_haltK_iff` — the contradiction both halves aim at: if `A` is r.e. and
  a computable `f` satisfies `n ∉ K ↔ A (f n)`, then the complement of the halting set would be
  r.e., contradicting `Lambda.not_rePred_not_haltK`.

## The two halves

* **`Lambda.Post.rePred_extensional_mono`** — an r.e. extensional class is **upward closed**.  If
  `A d` holds and `W d ⊆ W e` but `A e` fails, take the family
  `W (h n) = W d ∪ (W e if n ∈ K)`, uniformly computable by the test
  `acc d s x || (acc n s n && acc e s x)`.  If `n ∈ K` this set is `W e` (using `W d ⊆ W e`), so it
  is not in `A`; if `n ∉ K` it is `W d`, so it is.  Hence `n ∉ K ↔ A (h n)`.
* **`Lambda.Post.rePred_extensional_finite_witness`** — a member of an r.e. extensional class has a
  **finite** subset in the class.  If `A e` holds but no finite subset of `W e` is in `A`, take
  `W (h n) = {x | x is enumerated into W e at a stage before n halts}`, computable by the test
  `acc e s x && !(acc n s n)`.  If `n ∉ K` this is all of `W e`, so it is in `A`; if `n` halts at
  stage `s₀` then every element is bounded by `s₀` (by `acc_bound` and the monotonicity of the
  halting test), so the set is finite and a subset of `W e`, hence not in `A`.  Again
  `n ∉ K ↔ A (h n)`.

Together:

    Lambda.Post.rice_shapiro :
      REPred A → Extensional A → (A e ↔ ∃ d, {x | Wset d x}.Finite ∧ (∀ x, Wset d x → Wset e x) ∧ A d)

## Consequences

* **`Lambda.Post.not_rePred_emptyIndex`** — the class of indices of the *empty* set is not r.e.:
  it is extensional, so if it were r.e. it would be upward closed, and the empty set is contained
  in every set.
* **`Lambda.Post.not_rePred_totalIndex`** — the class of indices of the *total* functions is not
  r.e.: it would have to contain a finite set, and no finite set of numbers is all of `ℕ`.

## Boundary

The theorem is stated for classes of *indices* in mathlib's numbering `Nat.Partrec.Code`, with
finiteness of the witnessing set expressed as `Set.Finite`; no canonical indexing of the finite
sets is introduced.  The classical converse direction of the theorem — that a class generated by a
recursively enumerable family of finite sets is itself r.e. — is not formalized.
