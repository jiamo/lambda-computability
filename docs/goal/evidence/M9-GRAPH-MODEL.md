# M9-GRAPH-MODEL

**Status:** DONE_STRONG

Modules `Start/GraphModel.lean` and `Start/GraphModelSemantics.lean`, both imported by
`Start.lean`.  They build without `sorry` and without linter warnings.

## The reflexive object (first exit criterion)

`Start/GraphModel.lean` builds Scott's *graph model*.  Tokens are given by the inductive type
`GraphModel.Tok`, generated by atoms `atom : ℕ → Tok` and arrows `arrow : List Tok → Tok → Tok`;
the domain is `D := Set Tok`, ordered by inclusion, and `lset : List Tok → D` reads a finite list
as a finite element.

* `appD X Y = {b | ∃ a, lset a ⊆ Y ∧ arrow a b ∈ X}` is application;
* `graph f = {arrow a b | b ∈ f (lset a)}` turns a function into an element;
* `Cont f` says `f` is determined by its finite approximations, and
  `cont_iff_scottContinuous` identifies `Cont` with mathlib's `ScottContinuous` on `Set Tok`;
* `appD_graph` proves `appD (graph f) = f` for continuous `f`, so the continuous function space
  is a **retract** of `D`: `D` is a reflexive object.
* `graph_appD_ne` exhibits an element with `graph (appD X) ≠ X`, so the retraction is not an
  isomorphism and the model is *not* extensional (it does not validate eta).

Monotonicity lemmas (`graph_mono`, `appD_mono`, `graph_congr`) and continuity of `appD` in its
first argument (`scottContinuous_appD`) round out the interface.

## Interpretation and continuity (second exit criterion)

`Start/GraphModelSemantics.lean` defines `Env := ℕ → D`, `cons`, and

```
denot (var i) ρ = ρ i
denot (app s t) ρ = appD (denot s ρ) (denot t ρ)
denot (lam s) ρ = graph (fun X => denot s (cons X ρ))
```

`denot_mono` is monotonicity in the environment, `denot_fin` is the key finiteness statement (any
token in `⟦t⟧ρ` already appears in `⟦t⟧` of a *finite* environment), and `cont_denot_cons` derives
continuity of `X ↦ ⟦t⟧(X · ρ)`, which is what makes the lambda clause well behaved.

## Beta and soundness (third exit criterion)

`denot_lift` and `denot_subst` are the lifting and substitution lemmas; `denot_beta` is the
semantic beta rule `⟦(λt) s⟧ρ = ⟦t[s]⟧ρ`.  Soundness follows: `denot_step`, `denot_reduces` and
`denot_conv` show that a beta step, a multi-step reduction, and beta conversion all preserve the
denotation.

## Nontriviality (fourth exit criterion)

`denot_omega` proves `⟦Ω⟧ρ = ∅` by an infinite-descent argument on the syntactic size of tokens
(`Tok.size`, `maxSize`, `arrow_notMem_selfAppD`).  Since `denot_I_ne_empty` shows `⟦I⟧ρ ≠ ∅`,
`not_conv_omega_I` concludes that `Ω` is not beta convertible to `I`, and `exists_not_conv` that
the beta calculus is consistent.  This is a *semantic* consistency proof that does not use
confluence.

## Boundary

* Only beta is modelled.  The graph model is not extensional, so eta is not valid in it; the
  extensional model is `D∞` (task `M9-SCOTT-DINF`).
* No adequacy or completeness statement is proved: nothing here says that equal denotations imply
  convertibility.
