# v0.1.0 — first library release

`sorry`-free Lean 4 formalization of computability theory and algorithmic information theory,
carried out inside the untyped lambda calculus.  Milestones M1–M8 of the task board are complete
(`docs/goal/task-board.yaml`, 51/51 tasks `DONE_STRONG`); the whole `Start` library builds with
`lake build`, contains no `sorry` and no `axiom`, and the headline results depend only on
`propext`, `Classical.choice` and `Quot.sound`.

## Contents

* **Syntax and reduction theory** — de Bruijn terms, lifting/substitution theory, parallel
  reduction, confluence (`Lambda.confluence_theorem`), standardization, leftmost reduction.
* **Church–Turing equivalence** — `lambdaComputable_iff_partrec`,
  `TM2Partrec.tm2Computable_iff_partrec` and hence `lambdaComputable_iff_tm2Computable`:
  the lambda calculus, the partial recursive functions and Mathlib's TM2 machines compute
  the same partial functions.
* **Recursion theory** — Scott–Rice (`Lambda.scott_theorem`), s-m-n (`Lambda.exists_smn`),
  a self-interpreter (`Lambda.exists_self_interpreter`), Kleene's second recursion theorem with
  parameters, and one-one completeness of the lambda halting set
  (`Lambda.codeHasNormalForm_one_complete`).
* **Algorithmic information theory** — plain and prefix Kolmogorov complexity, Berry's paradox
  (`Lambda.not_computable_kolm`), Kraft's inequality (`Kraft.tsum_wt_le_one`), Chaitin's `Ω`
  (`Lambda.chaitinOmega_mem_Ioo`, `Lambda.irrational_chaitinOmega`), Martin-Löf randomness,
  the Levin–Schnorr theorem for the universal prefix machine
  (`KC.mlRandom_iff_exists_const_le_KU`), randomness of the bits of `Ω`
  (`KC.mlRandom_omegaSeq`), and optimality of that machine for the lambda prefix complexity
  (`KC.exists_const_KU_le_kolmP`).
* **Lambda calculus theory** — Böhm's separation theorem
  (`Lambda.separable_toTerm_of_not_tagEq`) and the binary lambda calculus bijection
  (`Lambda.bitsEquiv`).
* **Types, proof theory, complexity** — Tait strong normalization for the simply typed lambda
  calculus, canonicity for Gödel's System T, and a Blum-style speed-up statement
  (`Complexity.exists_computable_steps_gt`).

## Build

Lean `v4.33.0`, Mathlib `v4.33.0` (see `lean-toolchain` and `lakefile.toml`).  From a clean
checkout: `lake exe cache get` and then `lake build`.

## Known boundaries

Documented in the README roadmap: the second half of the `KU`/`kolmP` comparison, Schnorr
randomness and Solovay tests, Cook–Levin and NP-completeness, ordinal analysis, and reverse
mathematics are **not** formalized here.
